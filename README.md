# CMP_SC 3330 - Assignment 1
## Campus Event Tickets

### Environment
- IDE: Eclipse IDE for Java Developers
- Java: JavaSE-21
- Package: assignment1

### How to Run
1. Import the project into Eclipse.
2. Open `src/assignment1/Main.java`.
3. Right-click `Main.java`.
4. Select `Run As` > `Java Application`.
5. The results will appear in the Eclipse Console.

No user input is required. The demonstration data is hardcoded in `Main.java`.

### Program
The program creates campus events, ticket types, and tickets. It demonstrates:
- Creating and storing tickets
- Canceling a ticket
- Admitting a ticket
- Handling invalid ticket operations
- Printing all tickets
- Printing tickets for a specific event
